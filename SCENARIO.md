# КВАДРАНТ — предлагаемый сценарий MVP

Статус: согласован пользователем с уточнениями, версия 2 от 30.10.2026. Реализация ещё не начата.

Основание: [ТЗ v3.0](./kvadrant_mvp_10_12h_v3.md). Прогресс разработки: [PLAN.md](./PLAN.md).

## 1. История и учебная цель

Корабль «Квадрант» приближается к планете. Бортовой компьютер БИП готов восстановить маршрут, но ему нужна помощь с расчётами. Сначала ученик проходит калибровку на одном примере, затем самостоятельно рассчитывает два участка пути.

Математическая цель: распознать коэффициенты квадратного уравнения, вычислить дискриминант, понять связь его знака с числом действительных корней и найти корни по формуле.

Связь с игрой условная и объясняется явно: «В нашей навигационной системе корни задают координаты точки маршрута». Дискриминант остаётся математическим свойством уравнения. Он не становится топливом, скоростью или энергией корабля.

Тон БИПа: спокойный, дружелюбный, без оценок способностей ученика. Ошибки можно исправлять сколько угодно. Нет таймера, штрафов и проигрыша.

Ориентир прохождения — 6–8 минут; время не ограничивает ученика и не показывается как обратный отсчёт.

## 2. Карта прохождения

`Старт → Урок 1–5 → Задача 1: D → Задача 1: корни → Полёт 1 → Задача 2: D → Задача 2: корни → Полёт 2 → Финал`.

- Ошибка оставляет ученика на текущем шаге с сохранением введённых значений.
- Полный разбор раскрывает решение текущей задачи, но не запускает перелёт автоматически.
- В уроке доступны возвраты между уже открытыми шагами.
- В практике нет перехода к следующей задаче до успешной проверки текущей.
- Обязательного ввода коэффициентов в практике нет.
- Во время полёта ответ уже принят, повторная отправка заблокирована.

## 3. Старт — «КВАДРАНТ»

**На экране:** корабль, планета, название, пометка «9 класс · Подготовка к ОГЭ».

**Основной текст:** «Научись решать квадратные уравнения через дискриминант».

**Дополнительный текст:** «Короткий урок, две задачи и маршрут к планете».

**БИП, neutral:** «Привет! Я БИП, бортовой компьютер. Помоги рассчитать маршрут к планете. Начнём с одного примера — я покажу каждый шаг».

**Действие:** «Начать обучение» → первый шаг урока. Пропуск урока в первом прохождении не предлагаем.

## 4. Урок «Калибровка навигации»

Общий пример на всех шагах: `x² − 4x + 3 = 0`. Показываем «Шаг N из 5» и короткий заголовок. Один основной интерактивный блок на шаг. Правильный ответ не переключает экран автоматически: ученик читает обратную связь и нажимает «Далее».

### Шаг 1. Узнай коэффициенты

**БИП, neutral:** «Квадратное уравнение записывают так: ax² + bx + c = 0, где a ≠ 0. Найдём коэффициенты нашего примера. Знак перед числом тоже важен».

**Показ:** стандартная форма и пример под ней. Связать `ax²` с `x²`, `bx` с `−4x`, `c` с `+3` цветом и подписями.

**Действие:** три группы выбора:

| Коэффициент | Варианты | Правильный ответ |
| --- | --- | --- |
| a | 0; 1; −1 | 1 |
| b | 4; −4; −3 | −4 |
| c | 3; −3; 0 | 3 |

Кнопка «Проверить». Пока выбор не сделан во всех группах: «Выбери значение для каждого коэффициента».

**Ошибка:** отметить неверно выбранные группы. БИП: «Сравни пример со стандартной формой. Перед x² нет числа — его коэффициент равен 1. Коэффициент при x бери вместе со знаком».

**Успех, success:** «Верно: a = 1, b = −4, c = 3. Эти числа понадобятся для расчёта дискриминанта».

**Далее:** доступно после правильного ответа. «Назад» на первом шаге отсутствует.

### Шаг 2. Вычисли дискриминант

**БИП, neutral:** «Дискриминант помогает определить число действительных корней. Его формула: D = b² − 4ac. Подставим наши коэффициенты».

**Показ:** `D = (−4)² − 4 · 1 · 3`. Ниже: `(−4)² = 16`, `4 · 1 · 3 = 12`.

**Действие:** одно поле «D = 16 − 12 = …», кнопка «Проверить».

**Ошибка, warning:** «Вычти 12 из 16 и попробуй ещё раз».

**Успех, success:** «Получилось D = 4. Теперь посмотрим, что это означает на графике».

**Далее:** после ввода `4`. Можно вернуться к шагу 1.

### Шаг 3. Увидь корни на графике

**БИП, neutral:** «Корни уравнения — значения x, при которых y = 0. На графике это точки пересечения параболы с осью X. Меняй c и посмотри, что произойдёт».

**Действие:** три кнопки `c = 3`, `c = 4`, `c = 5`. Начальное состояние — `c = 3`. Уже просмотренные варианты помечены.

| Выбор | Функция | Дискриминант | Подпись под графиком |
| --- | --- | --- | --- |
| c = 3 | y = x² − 4x + 3 | 16 − 12 = 4 | D > 0: два действительных корня, x = 1 и x = 3 |
| c = 4 | y = x² − 4x + 4 | 16 − 16 = 0 | D = 0: один действительный корень, x = 2; парабола касается оси X |
| c = 5 | y = x² − 4x + 5 | 16 − 20 = −4 | D < 0: действительных корней нет; парабола не пересекает ось X |

Для всех вариантов использовать одинаковый масштаб и диапазоны осей, например X от −1 до 5 и Y от −2 до 7. Кривую обрезать по области графика. Отмечать точки на оси X только там, где они действительно существуют. Цвет дополнять формулой, числом и текстом.

**Подсказка под кнопками:** «Посмотри все три случая, чтобы продолжить».

**После просмотра всех вариантов, success:** «Знак D подсказывает число действительных корней: положительный — два, нулевой — один, отрицательный — ни одного».

**Далее:** после просмотра всех трёх вариантов; дополнительного теста на этом шаге нет. Выбор `c` влияет только на график. Следующий шаг явно возвращается к исходному примеру с `c = 3`.

### Шаг 4. Найди корни по формуле

**БИП, neutral:** «Вернёмся к x² − 4x + 3 = 0. Здесь D = 4, значит, есть два действительных корня. Подставим числа в формулу».

**Показ:** `x₁,₂ = (−b ± √D)/(2a)`.

**Действие:** кнопка «Показать следующий шаг» последовательно раскрывает:

1. `x₁,₂ = (4 ± √4)/(2 · 1)`. Комментарий: «Здесь −b = −(−4) = 4».
2. `√4 = 2`, поэтому `x₁,₂ = (4 ± 2)/2`.
3. `x₁ = (4 − 2)/2 = 1`, `x₂ = (4 + 2)/2 = 3`.

**После раскрытия, success:** «Корни — 1 и 3. Порядок записи не важен».

**Короткая памятка:** «При D = 0: x = −b/(2a). При D < 0 действительных корней нет».

**Далее:** после раскрытия третьего шага. Не требуем вручную повторять разобранные вычисления.

### Шаг 5. Подтверди калибровку

**БИП, neutral:** «Проверим, что сохранилось в памяти. Что получилось для x² − 4x + 3 = 0?».

**Действие:** выбрать одну из трёх карточек:

- `D = 4; корни 1 и 3` — правильная.
- `D = 4; корни −1 и −3`.
- `D = −4; действительных корней нет`.

Кнопка «Подтвердить».

**Ошибка, warning:** «Вспомни: D = 16 − 12, а корни мы получили из (4 ± 2)/2. Можно вернуться на предыдущий шаг».

**Успех, success:** «Калибровка завершена! Теперь рассчитай два участка маршрута. Формула и подсказки останутся рядом».

**Действие после успеха:** «К маршруту» → первая задача. Урок не добавляет баллы к практике.

## 5. Общие правила практики

В сцене корабль и планета, в терминале — номер участка, уравнение, реплика БИПа и текущая форма. Прогресс маршрута: «Участков пройдено: 0/2», затем «1/2» и «2/2».

### Стадия D

- Поле с подписью «Дискриминант D» и кнопка «Проверить D».
- Доступна компактная памятка `D = b² − 4ac`. Числовые коэффициенты не подставлены заранее.
- Корни и числовые координаты целевой точки скрыты.
- Неверный D: БИП, warning — «Пока неверно. Проверь коэффициенты и вычисление b² − 4ac». Поле сохраняется, задача не меняется.
- Верный D: БИП, success — «Верно, D = {значение}. Он положительный — найди два действительных корня». Открываются поля корней; принятый D отображается как результат без редактирования.

### Стадия корней

- Два отдельных поля «Первый корень x₁» и «Второй корень x₂».
- Памятка `x₁,₂ = (−b ± √D)/(2a)` и подтверждённый D остаются видны.
- Под полями: «Порядок корней не важен». Кнопка «Проверить корни».
- Неверный ответ: БИП, warning — «Эта пара корней пока не подходит. Используй D = {значение} и формулу x₁,₂ = (−b ± √D)/(2a). Попробуй ещё раз».
- Не сообщаем «ты забыл знак» или другую конкретную причину, потому что промежуточные вычисления неизвестны.
- При успехе показать корни в возрастающем порядке, координаты точки и запустить перелёт ровно один раз.

### Некорректный ввод на обеих стадиях

- Пустое поле: «Введи значение D» или «Введи оба корня».
- Некорректная строка: «Введи число. Например: −2 или 1,5».
- Некорректный ввод не считается математической ошибкой и не запускает красную вспышку.
- После редактирования убрать устаревшую ошибку; при этом сохранять уже раскрытые подсказки.
- Enter отправляет текущую форму. На время полёта отправка отключена.

## 6. Участок 1 — «Первая точка маршрута»

**БИП, neutral:** «Начнём с первой точки. Вычисли дискриминант уравнения x² − 5x + 6 = 0».

**Эталон:** `a = 1`, `b = −5`, `c = 6`; `D = 25 − 24 = 1`; корни `2` и `3`.

### Подсказки для D

1. «Определи a, b и c вместе со знаками. Затем вычисли b² и вычти 4ac».
2. «Здесь a = 1, b = −5, c = 6. Подставь: D = (−5)² − 4 · 1 · 6».

### Подсказки для корней

1. «Подставь коэффициенты и D в формулу. Вычисли отдельно вариант с плюсом и вариант с минусом».
2. «Получится x₁,₂ = (5 ± √1)/2. Вся разность или сумма в числителе делится на 2».

### Полный разбор

`D = (−5)² − 4 · 1 · 6 = 25 − 24 = 1`.

`x₁,₂ = (5 ± √1)/2 = (5 ± 1)/2`.

`x₁ = (5 − 1)/2 = 2`; `x₂ = (5 + 1)/2 = 3`.

### Успех и полёт

**БИП, success:** «Корни — 2 и 3. В нашей навигационной системе меньший корень задаёт X, больший — Y. Первая точка: (2; 3). Прокладываю маршрут!».

Корабль летит к промежуточной точке, затем открывается участок 2. Участок маршрута отмечается как пройденный после завершения перелёта.

## 7. Участок 2 — «Курс на планету»

**БИП, neutral:** «Первая точка пройдена! Остался участок до планеты. Здесь a = 2 — учти это в вычислениях. Найди D для 2x² − 8x + 6 = 0».

**Эталон:** `a = 2`, `b = −8`, `c = 6`; `D = 64 − 48 = 16`; корни `1` и `3`.

### Подсказки для D

1. «Используй D = b² − 4ac. В этом уравнении коэффициент a равен 2».
2. «Подставь a = 2, b = −8, c = 6: D = (−8)² − 4 · 2 · 6».

### Подсказки для корней

1. «Найди √D и вычисли 2a. На 2a нужно разделить весь числитель».
2. «Подставь значения: x₁,₂ = (8 ± √16)/(2 · 2)».

### Полный разбор

`D = (−8)² − 4 · 2 · 6 = 64 − 48 = 16`.

`x₁,₂ = (8 ± √16)/(2 · 2) = (8 ± 4)/4`.

`x₁ = (8 − 4)/4 = 1`; `x₂ = (8 + 4)/4 = 3`.

### Успех и полёт

**БИП, success:** «Верно! Корни — 1 и 3. Точка назначения: (1; 3). Курс на планету!».

Корабль долетает до планеты, прогресс становится `2/2`, открывается финал.

## 8. Как работают помощь и полный разбор

- На каждой стадии сначала доступна кнопка «Подсказка», затем «Ещё подсказка».
- После второй подсказки обе подсказки остаются видны; повторное нажатие не добавляет одинаковые сообщения.
- Под подсказками доступно отдельное действие «Показать полный разбор» с пояснением: «Участок можно завершить, но эта задача будет отмечена как выполненная с разбором».
- Действие раскрывает полный разбор только текущей задачи и сразу устанавливает для неё признак просмотра решения. Закрытие разбора не отменяет этот признак.
- Если разбор открыт на стадии D, ученик всё равно вводит D, проходит его проверку, затем вводит корни. Ответы не заполняются автоматически.
- Во время просмотра разбора координаты и траектория не появляются. Они открываются только после принятия введённых корней.
- Полный разбор не пропускает задачу и не переносит ученика к следующему участку.
- Обычные подсказки не влияют на итог: их использование не подсчитывается и не отображается в финале. Уровень раскрытия хранится только для последовательного показа подсказок внутри текущей задачи.
- Для итогов сохраняется только признак просмотра полного разбора по каждой задаче; новое прохождение его сбрасывает.

## 9. Пространство и анимация маршрута

- Участок 1 ведёт к промежуточной точке, участок 2 — к планете. Астероиды служат фоном, препятствий и столкновений нет.
- Координаты — игровая абстракция, получаемая из корней. Координатной сетки, осей и объяснений локальных систем координат в космической сцене нет. Позиции корабля, промежуточной точки и планеты выбираются для композиции сцены, а не вычисляются по корням.
- Сцена — схематичная карта экспедиции; условные числовые координаты показываются в карточке точки после решения. Оси в учебном графике параболы сохраняются: это отдельная математическая иллюстрация.
- До решения видны планета и общий путь экспедиции, но нет числовых подписей цели и точной решённой траектории.
- После принятия корней показать подпись координат и примерно двухсекундный перелёт. В это время терминал сообщает «Прокладываю маршрут…» и не принимает повторную отправку.
- В reduced motion заменить движение коротким статичным сообщением об успехе, затем переключить участок. Переход работает независимо от CSS-события завершения анимации.

## 10. Финал — «Маршрут восстановлен!»

**Показ:** корабль у планеты; «Участков пройдено: 2/2».

**БИП, success:** «Мы у цели! Ты прошёл путь от коэффициентов до корней квадратного уравнения».

**Итоги:**

- «Самостоятельно, без полного разбора: N из 2».
- Использование обычных подсказок в финале не упоминается и на итог не влияет.
- Если открывался полный разбор: «С полным разбором: N из 2». Дополнительная реплика: «Можно пройти ещё раз и попробовать без разбора».
- Если полный разбор не открывался: «Обе задачи решены без полного разбора». Эта формулировка не зависит от использования обычных подсказок.

**Короткая памятка:** «Коэффициенты → D = b² − 4ac → число действительных корней → формула корней».

**Основная кнопка «Пройти снова»:** сбросить прошлую практику и начать задачу 1. Повторный просмотр урока не обязателен.

**Вторая кнопка «Повторить теорию»:** сбросить урок и практику, открыть первый шаг урока. После мини-калибровки начинается новая практика.

## 11. Возвраты и сохранение состояния

| Действие | Поведение |
| --- | --- |
| «Назад» в уроке | Предыдущий шаг; ответы, просмотр графиков и раскрытые вычисления сохраняются |
| Изменение принятого ответа в уроке | Снять успех этого шага, пока новый ответ не проверен; уже открытые следующие шаги и их данные не сбрасывать |
| «Далее» после возврата | Доступно при выполненном условии текущего шага |
| Ошибка или открытие подсказки в практике | Оставить задачу, введённые значения и принятую стадию D |
| Переход к задаче 2 | Очистить поля, ошибки и раскрытые подсказки формы; результат задачи 1 сохранить |
| Повторное нажатие во время полёта | Никакого дополнительного действия |
| Перезагрузка страницы | Старт нового прохождения; в MVP сохранения нет |
| Системная кнопка браузера «Назад» | Экраны MVP не создают отдельных записей истории; внутренняя навигация выполняется кнопками приложения |

## 12. Сценарии, которые нужно проверить при реализации

1. Новичок проходит пять шагов, обе задачи и финал без подсказок.
2. Ученик ошибается в коэффициентах и D урока, исправляет ответы и продолжает.
3. Ученик возвращается к предыдущим шагам: ответы не теряются, график и формулы остаются согласованными.
4. В практике неправильный D не открывает корни, неправильные корни не запускают полёт.
5. Переставленные корни принимаются; пустое поле и повтор одного корня не принимаются.
6. Обе ступени подсказок не раскрывают готовый ответ и не меняют финал; только полный разбор меняет отметку о самостоятельном решении.
7. Разбор открыт до ввода D: прохождение остаётся последовательным, автоподстановки нет.
8. Одну задачу решили без разбора, другую с разбором: финал показывает 2/2 участка, 1/2 самостоятельно, 1/2 с разбором.
9. Быстрые повторные нажатия не запускают несколько перелётов и не пропускают задачу 2.
10. «Пройти снова» и «Повторить теорию» начинают соответствующие чистые сценарии.
11. На телефоне поля доступны при прокрутке; клавиатура не создаёт тупика.
12. С reduced motion обе задачи и финал доступны без обязательного ожидания анимации.

## 13. Согласованные решения

Эти детали конкретизируют ТЗ и согласованы пользователем с уточнениями:

1. Мини-калибровка — один выбор готовой пары «D и корни», чтобы не повторять полноценную задачу.
2. На графике достаточно посмотреть три состояния; дополнительный тест не добавляем.
3. Полный разбор не заполняет ответы и не запускает полёт: ученик завершает ввод сам, задача помечается как выполненная с разбором.
4. Обычные подсказки в финале не учитываем. Сохраняем только различие между решением без полного разбора и с полным разбором.
5. «Пройти снова» сразу открывает практику; «Повторить теорию» начинает весь учебный путь.
6. Координаты — условное обозначение маршрута без координатной сетки и локальных систем координат. Положение объектов в сцене не зависит от числовых значений корней.
